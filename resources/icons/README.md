# Application icon

The SimNodus icon (blue/cyan chip with "SN"), provided by the owner on
2026-10-15 as `SimNodus_Icones_Windows_macOS_PNG.zip`; original SimNodus
material under the repository's MIT license. Raster images, no vector
source.

| File | Use |
|---|---|
| `simnodus.ico` | Windows executable icon (16–256 px), through `apps/simnodus/simnodus.rc.in` |
| `simnodus_<size>.png` | Window icon (`icons.qrc`, 16–256 px) and Linux `share/icons/hicolor` (16–512 px) |

Not kept from the package: the macOS `.icns` (macOS is not a target), the
1024 px and 20/40/96 px images, the dark-background variant, the original
and the preview sheet.
